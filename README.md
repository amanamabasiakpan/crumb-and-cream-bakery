# Crumb & Cream Bakery

Premium website template for a Lagos cake and pastry business.

**Tagline:** Beautifully baked. Made for your moments.

## What’s included

- Food-photography-first landing page
- Cake, pastry, and dessert-box menus with WhatsApp ordering
- Interactive order builder with a pre-filled WhatsApp message
- Gallery lightbox, testimonials, FAQ, delivery areas
- Light and dark mode
- Mobile-first layout

## Customize

All brand content lives in `src/lib/site.ts`:

- Business name, tagline, and copy
- WhatsApp number, email, Instagram
- Products, prices, and images
- Delivery areas and testimonials

Replace files in `public/images/` to swap photography.

## Stack

TanStack Start, React, TypeScript, Tailwind CSS.
